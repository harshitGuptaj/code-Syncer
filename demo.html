How It Works

1

Create a Room

Enter your name and click "Create Room" to get a unique Room ID. Share this ID with your collaborators.

2

Share the Link

Send the Room ID to your team members. They can join by entering the same Room ID and their username.

3

Start Coding

Everyone in the room sees changes in real-time. Code, chat, draw, and execute code together.

4

Collaborate

Use the AI Copilot for code suggestions, the drawing board for brainstorming, and the chat for communication.

Features

Real-Time Syncing

Instant code synchronization across all participants using WebSockets.

25+ Languages

Execute code in JavaScript, Python, Java, C++, Go, Rust, and many more.

AI Copilot

Get AI-powered code suggestions powered by Groq API.

Drawing Board

Built-in whiteboard with tldraw for visual collaboration.

In-Room Chat

Real-time messaging system for team communication.

File Management

Create, rename, delete, and organize files and directories.

Tech Stack

Frontend

React 18, TypeScript, Vite, Tailwind CSS, CodeMirror 6, Socket.IO Client, tldraw

Backend

Node.js, Express, Socket.IO, TypeScript

Code Execution

Judge0 API - Execute code in 25+ programming languages

AI Integration

Groq API - Fast AI inference for code suggestions
